# ProjectTwin

AI-Powered Digital Twin for Software Projects.

## Current stage

This starter version contains the first building block:

**Project scanning**

ProjectTwin discovers files inside a software project. Later stages will progressively add:

1. Code parsing
2. Functions and class extraction
3. Import/dependency analysis
4. Knowledge base
5. Embeddings and vector search
6. Dependency graph
7. Git history intelligence
8. RAG + LLM
9. Change-impact analysis
10. AI-assisted bug investigation

The project is being developed incrementally.
